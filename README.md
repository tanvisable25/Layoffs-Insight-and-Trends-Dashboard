# Layoffs-Insight-and-Trends-Dashboard
📊 Overview

The Layoffs Insights and Trends Dashboard is an interactive Power BI project designed to analyze global layoff data from 2020–2024. The project aims to uncover key trends, patterns, and insights across industries, companies, and countries affected by large-scale layoffs during this period.

This analysis helps users and decision-makers understand which sectors and regions were most impacted, track changes over time, and identify recovery or growth phases post-layoffs.


🧠 Project Objectives

To visualize the overall trend of layoffs globally.

To identify the most affected countries and industries.

To analyze year-wise and month-wise layoff patterns.

To evaluate company-wise layoffs and workforce impacts.

To provide a clear, data-driven overview of global employment shifts.

⚙️ Tools & Technologies Used

Power BI – for data visualization and dashboard creation

Microsoft Excel – for data cleaning and preprocessing

SQL/MySQL – for data extraction and transformation (if applicable)

DAX – to create calculated measures and KPIs


📈 Key KPIs & Metrics

The dashboard includes several performance indicators and visuals:

Total Layoffs – Overall number of employees laid off (2020–2024)

Companies Affected – Total companies involved in layoffs

Top Countries – Countries with the highest layoff counts

Industry Trends – Sector-wise analysis of layoffs

Layoffs Over Time – Year-wise and month-wise trends

Company Size Impact – Relation between company size and layoff magnitude

Top Affected Companies – Visual ranking by layoff volume

🌍 Data Coverage

Region: Global

Time Period: 2020 – 2024

Dataset Source: Layoffs dataset (layoffs.csv) compiled from verified public records and company disclosures

💡 Insights & Findings

The tech sector and manufacturing industries show the highest layoff rates.

2023 recorded the peak layoff activity, followed by a gradual decline in 2024.

United States, India, and the United Kingdom are among the top affected regions.

Startups and mid-sized companies contributed significantly to the overall layoffs trend.

Seasonal trends suggest layoffs often cluster around Q1 and Q4.

📊 Dashboard Features

Interactive filters by Year, Country, and Industry

Dynamic cards displaying key KPIs

Bar and Line Charts showing trends over time

Map Visualizations for country-wise distribution

Conditional color formatting (e.g., maroon for high layoff zones)


📘 Conclusion

This project provides valuable insights into global layoff patterns, highlighting economic shifts, sector-specific vulnerabilities, and recovery periods.
It demonstrates how Power BI can transform raw HR and financial data into actionable intelligence for strategic planning and workforce analysis.
